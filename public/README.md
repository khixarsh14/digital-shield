# Preserved legacy demo material

This folder contains earlier chat-style demo source, fixtures, and audio. It is
preserved to avoid deleting substantive existing work during architecture alignment.

It is outside the active Vite application's `frontend/public/` directory and is
not used by that app. It is not a second frontend being developed and must not be
presented as an implemented WhatsApp channel. WhatsApp belongs only to the future
integration vision and pitch animation.

Active development uses `frontend/` and `backend/`; see `../docs/architecture.md`.
